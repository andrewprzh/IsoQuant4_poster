\section{Introduction}
\justifying
Single-cell and spatial transcriptomics combined with long-read sequencing
enable isoform-level expression profiling and the study of alternative
splicing. However, processing such data poses distinct algorithmic
challenges: error-prone reads, extremely large barcode whitelists, molecule
concatenation artifacts and PCR duplicates, as well as a lack of methods for
detecting spatially variable isoforms. Here we present
\textbf{IsoQuant4}~\cite{prjibelski2023} --- a universal toolkit for
processing long-read RNA-seq data obtained with various protocols ---
complemented by \textbf{Spl-IsoFind}~\cite{michielsen2026}, which discovers
spatially variable isoforms.

\section{Key features}
\justifying
\begin{itemize}
  \item Gene, transcript, exon and splice junction quantification for bulk,
        single-cell and spatial long-read data (PacBio and ONT);
  \item Reference-based and \textit{de novo} transcript discovery;
  \item High-precision barcode calling for 10x single-cell, Visium and
        Visium HD, Curio and Stereo-seq;
  \item Universal barcode calling for any custom protocol via a
        user-specified molecule description format;
  \item cDNA de-concatenation and UMI-based PCR deduplication;
  \item Detection of polyadenylation sites and TSS, fusion gene discovery;
  \item Open source: \texttt{github.com/ablab/IsoQuant} (PyPI and Bioconda).
\end{itemize}

\section{Spatial isoform variability}
\justifying
Spatially variable isoform expression detected with spot-based protocols may
reflect either true variability within a single cell type or differences in
regional cell-type composition. Single-cell resolution allows
distinguishing these two scenarios by testing isoform variability within
each cell type separately.
\begin{figure}
    \centering
    \includegraphics[width=0.92\textwidth]{figures/variability.pdf}
    \caption{\sffamily Apparent spatial variability (top) can be explained
    by cell-type abundance alone; true within-cell-type variability (bottom)
    requires single-cell resolution to be detected.}
    \label{fig:variability}
\end{figure}

\section{Spl-IsoFind detects spatially variable isoforms}
\justifying
Spl-IsoFind detects spatially variable isoforms using Moran's~$I$ spatial
autocorrelation of relative isoform expression; significance is assessed
with a permutation test. Combined with region-wise isoform tests, it detects
both known patterns and signals not aligned with predefined anatomical
regions.
\begin{figure}
    \centering
    \includegraphics[width=0.99\textwidth]{figures/splisofind.pdf}
    \caption{\sffamily Moran's $I$ is computed on the observed data
    ($I_{\mathrm{OBS}}$) and on permuted data ($I_{\mathrm{PERM}}$); the
    empirical P-value compares the original score to the permuted
    distribution.}
    \label{fig:splisofind}
\end{figure}

\section{Spatially variable isoforms in mouse brain}
\justifying
Applied to mouse brain spatial long-read datasets with nanometer resolution,
our toolkit discovers spatially variable isoforms at single-cell level.
\begin{figure}
    \centering
    \includegraphics[width=0.99\textwidth]{figures/sv_isoforms.pdf}
    \caption{\sffamily Spatially variable isoforms per cell type (ALL: all

\section{Conclusions}
\justifying
\begin{itemize}
  \item First demonstration of long-read spatial isoform mapping at
        single-cell resolution;
  \item Combined long-read sequencing with Stereo-seq and 10x Visium HD;
  \item Developed a universal pipeline (IsoQuant4) for bulk, single-cell
        and spatial long-read data;
  \item Created a package (Spl-IsoFind) for detecting spatially variable
        isoforms;
  \item Revealed cell-type-specific spatially variable isoforms in adult
        mouse brain.
\end{itemize}
