\section{Introduction}
\justifying
Single-cell and spatial transcriptomics combined with long-read sequencing
enable isoform profiling and the study of alternative splicing at the cellular level.
We present \textbf{IsoQuant4} --- a universal toolkit for processing
long-read RNA-seq data, \textbf{\mbox{Spl-IsoFind}} --- a package for discovering spatially variable isoforms, and their application to mouse brain data.

\section{IsoQuant4 features}
\justifying
\hspace*{1cm}% shift the list right
\begin{minipage}{\dimexpr\textwidth-1cm}
\begin{itemize}
  \addtolength{\itemsep}{0.2ex}

        \addtolength{\itemsep}{0.1ex}
        \item Genes / isoforms
        \item Exons / splice junctions / intron retentions
        \item Works for bulk, single-cell and spatial data
  \end{itemize}
  \item Reference-based and \textit{de novo} transcript discovery
  \item Barcode calling
  \vspace{0.1ex}
  \begin{itemize}
        \addtolength{\itemsep}{0.1ex}
        \item 10x single-cell v2 / v3 / v4
        \item 10x Visium / Visium HD
        \item Curio Biosciences
        \item Stereo-seq
        \item cDNA de-concatenation
  \end{itemize}
  \item Universal barcode calling for any custom protocol
  \item PCR deduplication
  \item Poly(A) site and TSS detection
  \item Fusion gene discovery
\end{itemize}
\end{minipage}

\section{Spl-IsoFind}
\justifying
Spl-IsoFind detects spatially variable isoforms linked and not linked to pre-defined brain regions.
The latter is detected via Moran's~$I$ spatial autocorrelation and permutation tests.

\section{Conclusions}
\justifying
\begin{itemize}
  \addtolength{\itemsep}{1ex}
  \item A universal tool for bulk, single-cell and spatial long-read data
  \item A package for detecting spatially variable isoforms
  \item First long-read spatial isoform mapping at single-cell resolution
  \item Cell-type-specific spatially variable isoforms in adult mouse brain
 \end{itemize}
